# Attendance Management System

A Python-based Attendance Management System designed to simplify student attendance tracking and reporting.

## Features

- Track student attendance by date.
- Calculate individual attendance percentages.
- Check whether a student was present or absent on a specific date.
- Mark, update, and remove attendance records.
- Calculate average class attendance.
- Store student records in JSON format.
- AI integration testing for future natural-language attendance queries.

## Technologies Used

- Python
- JSON
- Hugging Face Inference API (initial integration testing)

## How to Run

1. Install Python 3.10 or later.
2. Clone or download this repository.
3. Open the project folder in Terminal.
4. Run:

   python3 main.py

## Data Storage

Student records and attendance information are stored in `students.json`.
